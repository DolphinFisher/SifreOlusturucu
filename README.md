# Şifre Oluşturucu (Password Generator)

Modern, kullanıcı dostu ve güvenli bir şifre oluşturma uygulaması.

## Özellikler

- **Özelleştirilebilir Uzunluk:** 8 ile 64 karakter arasında şifre oluşturma.
- **Karakter Seçenekleri:** 
  - Büyük Harfler (A-Z)
  - Rakamlar (0-9)
  - Özel Karakterler (!@#$%^&*)
- **Güç Göstergesi:** Şifrenizin ne kadar güvenli olduğunu (Zayıf/Orta/Güçlü) anlık olarak görün.
- **Kopyalama Kolaylığı:** Tek tıkla oluşturulan şifreyi panoya kopyalayın.
- **Görünürlük Kontrolü:** Şifreyi gizleyin veya görüntüleyin.

## Kurulum ve Kullanım

Bu proje statik bir web sitesidir. Kullanmak için herhangi bir kuruluma ihtiyacınız yoktur.

1. Projeyi indirin veya klonlayın.
2. `index.html` dosyasını tarayıcınızda açın.

## Teknolojiler

- JavaScript (Vanilla)
